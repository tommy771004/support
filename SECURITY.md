# Security policy

This repository publishes a static support page. It holds no credentials and collects no personal data.

To report a vulnerability (for example a way to change where a payment link points, or to inject content into the page), use **Security → Report a vulnerability** on this repository. Please do not open a public issue.

如發現安全問題（例如能竄改付款連結、或在頁面注入內容），請使用本 repo 的 **Security → Report a vulnerability** 私下回報，不要開公開 issue。
